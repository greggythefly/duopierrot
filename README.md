# DuoPierrot · Writing Quest

Appli de révision d'anglais pour la Première, façon Duolingo : connecteurs logiques, structures grammaticales, méthode de production écrite en 7 étapes et lettre argumentative.

- Répétition espacée, rappel actif, exercices entrelacés.
- Phrases anglaises pré-enregistrées avec une voix britannique (`audio.js`).
- Progression enregistrée dans le navigateur (localStorage), avec export / import depuis l'onglet **Progrès › Sauvegarde**.

Aucune dépendance : il suffit d'ouvrir `index.html`.
